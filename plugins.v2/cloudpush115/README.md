MoviePilot V2：本地扫描、失败重试和 qB 下载完成后 SHA1 秒传。默认保留原文件。此次发布验收 V2，未以兼容导入作为 V3 实机验证。

## 可选文件策略

- `failure_move_enabled` 默认关闭，`failure_move_dir` 为 MP 容器内绝对路径。禁止目标位于监控目录内，避免循环扫描；可选保留监控根下相对结构，qB 独立文件无监控根时保留文件名。
- `failure_move_on=each_failure`：首次失败归档，后续沿归档路径重试，不重复改名移动。适用于无限重试。
- `failure_move_on=exhausted`（默认策略）：初次失败加上配置的最大重试次数耗尽后归档；启用时必须设置有限次数。qB 按文件失败次数判断移动时机，其重试由种子 watcher 继续管理。
- 网络／登录错误也算失败，远端结果可能未知；未明确成功绝不删除。明确未命中且关闭未命中重试的跳过项不移动、不删除。
- `delete_on_success` 默认关闭。只有明确成功、结果及动作意图持久化后才删除，并再次复核大小、mtime_ns、设备和 inode。文件变化则保留；本地动作异常独立记录，远端 success 不变。
- 历史保存原路径、当前路径、动作状态和错误。归档同步重试队列、账本及本地库存；qB 用原路径关联新路径，重启后仍可核对。已确认删除文件通过同账户／目标账本和原大小核对，仅全部选中媒体成功才打完成标签。
- 删除或移动会影响 qB 做种，请仅在接受这一影响时启用。

只处理普通文件，拒绝软链。同名冲突生成唯一名称，绝不覆盖；同盘通过 no-overwrite link/unlink，跨盘顺序复制到独占临时文件，fsync 并复读校验摘要、复核源签名后发布和删源。异常保留源文件。极端崩溃可能留下副本或 pending 意图，不自动重放未完成动作；文件仍需稳定，签名检查不能取代快照或阻止外部写入者。

## 机械盘 SHA1

4 MiB readinto 可复用缓冲；支持时设置顺序读取建议。2048 项内存 LRU，键含路径、设备、inode、大小和纳秒修改时间。相同文件并发计算只读一次；两插件在同一 Python 进程共享缓存、同设备读锁与文件动作锁，减少重复读及同设备交错读。缓存不跨重启，也不跨进程；不同分区属于同一物理盘的情况不作拓扑识别。

首次 SHA1 仍需完整读取文件，受机械盘吞吐限制，不承诺倍速。回归使用临时文件和 fake 115/qB，验证摘要一致、只读一次及文件动作安全；没有访问真实网盘、种子服务或用户文件。
