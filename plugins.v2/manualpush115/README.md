# 手动秒传115 · 1.8.0

用于补传自动秒传漏掉或失败的文件。本插件不设置自动扫描定时器，不移动、删除或改写源文件。

## 操作

1. 从 MoviePilot 插件市场将**手动秒传115**升级到 **1.8.0**，关闭旧页面后重新打开。已有Cookie、默认目标、扩展名与历史记录保留。
2. 首页右上角“设置”可编辑Cookie和默认值。完整 Config 联邦组件保留，也支持插件齿轮入口保存。
3. 点击首页“本地秒传路径”的输入框打开下拉选择器。初始仅列 MP 的本地下载/媒体目录和 Docker 挂载根目录，不预读子目录。
4. 点击目录名称或“进入”只读取下一层；用面包屑/“返回上级”导航。勾选与进入是两种独立操作，可勾选单文件、文件夹以及跨层多选；“选当前文件夹”选中整个当前目录。
5. 进入一个根后可按名称搜索。默认仅搜索当前层，勾选“包括子目录”后再点搜索/回车才执行递归；输入文字不会自行扫描。结果可以勾选或定位目录。每次搜索最多检查10000节点、保留500匹配、协作式时间预算3秒；达到限制会显示结果不完整。
6. 点击“115目标目录”从真实网盘目录逐层选择。只在打开选择器或切换网盘层级时请求，不会在加载设置时遍历网盘。
7. 点“开始秒传”，直接提交当前选择，无需先保存本地路径。选文件夹时后台收集文件；默认保留文件夹名称及相对子目录。
8. 任务进度、剩余数和成功/失败记录显示在首页。运行中每2秒查询本地任务状态，页面隐藏时暂停查询；点击停止会等当前文件结束，不丢未处理数量。

## 补传规则

- 默认重新尝试所选文件，不会仅凭旧成功历史阻止人工补传。
- 可选“跳过同账户/目标未变化的成功项”；只在账户、目标路径、源文件路径和文件签名均一致时跳过。
- 选择父目录和其中的文件/子目录不会重复处理，同名独立目录会分隔目标命名空间。
- 目录默认仅收集媒体与常见附属扩展；设置 `*` 可包含所有常规文件。显式单文件选择不受目录递归的扩展过滤影响。
- 单个失败保留记录并继续；Cookie失效或连续10个文件失败会停止，显示未完成数量。
- 每个文件结束后保存历史；异常退出后的旧任务显示“已中断”，不会擅自恢复上传。
- 115未命中秒传时显示失败；插件不会偷偷上传整个文件。

## 路径与宿主

仅使用 **MP容器内路径**，不读取 Docker 宿主机未挂载的路径。根目录来源包括 DirectoryHelper 中独立的本地下载/媒体库存储配置与 `/proc/self/mountinfo` 挂载目标；空格转义会解码，系统和文件挂载不作为选择根。不跟随符号链接，不遍历根外路径。

本次发布并验收的是 MoviePilot **V2** 实现。V3 的独立市场索引与实际宿主验证尚未作为本次功能验收，不能以 import 回退代替完整迁移验证。

```sh
PYTHONDONTWRITEBYTECODE=1 python -m pytest tests/manualpush115 tests/cloudpush115 -q
cd plugins.v2/manualpush115
pnpm install --frozen-lockfile
pnpm test
pnpm build
pnpm test:build
```

前端 Page/Config/AppPage 都包含在 `dist/assets`。发布必须保留 remoteEntry 引用的全部 JS/CSS（含 Workbench chunk）。样式不打包 Vuetify 全局 CSS。旧V2只传 api 时从其 PluginDataDialog/PluginConfigDialog 父级 plugin.id 取得实例ID，新版优先实例props，避免跨分身读写。
