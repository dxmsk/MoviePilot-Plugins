# MoviePilot Plugins

个人 MoviePilot V2 插件仓库。

## 插件列表

### 115网盘秒传 (CloudPush115)

把 MoviePilot 媒体库（或任意本地路径）中的文件以 **SHA1 秒传**方式推送到 115 网盘，**不上传文件本体**，节省带宽与时间。

**核心特性**

- 🚀 **秒传**：基于 SHA1 快传，不下载 / 不上传文件本体
- 🔗 **qBittorrent 下载完成联动**：种子下载完成即自动秒传到 115
  - 秒传成功 → 给种子打上「已整理」标签，**MoviePilot 跳过整理**（脱离整理队列）
  - 秒传失败 → 不打标签，**交由 MoviePilot 正常整理**
  - 已带「已整理」标签的种子 → 跳过，不再重试秒传
- 🔑 **两种登录**：网页 Cookie / 开放平台 access_token
- 📱 **扫码登录**：插件内直接生成 115 登录二维码
- 📂 **可视化选目录**：浏览 115 网盘目录树，点选目标目录
- 🔁 **失败重试**：自定义重试间隔与最大次数
- 🛡️ **全程只读**：绝不移动 / 修改 / 删除原始文件

**安装**

1. MoviePilot → 设置 → 插件 → 插件市场 → 添加仓库：
   ```
   https://github.com/dxmsk/MoviePilot-Plugins
   ```
2. 在插件市场找到「115网盘秒传」安装即可。

**使用要点**

- 登录方式选「网页 Cookie」，粘贴浏览器里的 115 Cookie（支持 JSON / DevTools / Netscape / cURL 等多种格式），或点「扫码登录」。
- qb 联动：打开开关，qb 地址可留空自动读取 MoviePilot 已配置的 qbittorrent。
- 「秒传成功标签」默认 `已整理`，**请勿修改**（必须与 MoviePilot 内部整理标签一致）。

**依赖**

零第三方依赖（纯 Python 标准库实现 AES/RSA/LZ4）。
